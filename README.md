# 機車小幫手

以單一 HTML 檔案製作的響應式機車管理網頁原型，可在桌面與手機瀏覽器使用。這不是原生 iOS App，無需安裝套件或建置工具。

## 開始使用

需要安裝 Python 3。在專案目錄執行：

```sh
python3 -m http.server 4173
```

接著用瀏覽器開啟 <http://localhost:4173>。停止伺服器時，在執行指令的終端機按 `Ctrl+C`。

## 功能

- **保養紀錄**：首頁顯示目前里程與車牌；可新增、編輯、刪除保養日期、里程及內容。
- **年度驗車**：記錄每次驗車日期，可新增、編輯、刪除，並顯示下一次驗車日期與倒數。
- **車輛證件**：可上傳、預覽、更換或刪除行照與駕照的圖片或 PDF。
- **CSV 備份**：保養與驗車紀錄可匯出或匯入 CSV。匯入會取代目前的保養與驗車資料。

預設車輛為「小白」，車牌 `PAB-6992`，目前里程 2,000 公里；預設含兩筆保養紀錄與兩筆驗車紀錄。

## CSV 欄位

匯出的 CSV 使用 UTF-8 編碼，欄位如下：

```text
類型,車名,車牌,次數,日期,總里程(公里),保養內容,目前里程(公里)
```

類型為「保養」或「驗車」，日期格式為 `YYYY/MM/DD`。驗車資料的總里程與保養內容留白。匯入時也支援不含「目前里程(公里)」的舊版七欄 CSV。

行照與駕照是二進位檔案，不會包含在 CSV 中。

## 資料保存與隱私

保養、驗車及車輛資料保存在目前瀏覽器與網址的 `localStorage`；行照與駕照檔案保存在同一瀏覽器的 IndexedDB。資料不會上傳到伺服器，也不會在不同瀏覽器或裝置間自動同步。清除瀏覽資料或更換裝置前，請先匯出 CSV；證件檔案需另外自行備份。

此原型不會額外加密證件檔案。請勿在不受信任的共用裝置上儲存敏感證件。
