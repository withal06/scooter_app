# 機車小幫手

以 HTML 與 Python 標準函式庫製作的響應式機車管理網頁原型，可在桌面與手機瀏覽器使用。這不是原生 iOS App，無需安裝套件或建置工具。

## 開始使用

需要安裝 Python 3。在專案目錄執行：

```sh
python3 server.py
```

接著用瀏覽器開啟 <http://localhost:4173>。伺服器同時提供中油牌價查詢 API；若 4173 埠已被舊伺服器占用，先在舊伺服器終端機按 `Ctrl+C` 停止它。也可改用其他埠，例如 `PORT=4174 python3 server.py`。

## 功能

- **保養紀錄**：首頁顯示目前里程與車牌；可新增、編輯、刪除保養日期、里程、內容及費用。
- **年度驗車**：記錄每次驗車日期，可新增、編輯、刪除，並顯示下一次驗車日期與倒數。
- **油耗與支出統計**：油耗頁自動查詢並顯示中油最新 92／95／98 無鉛牌價；新增加油紀錄時會依油量與所選油品預填加油金額，也可按收據調整。以整合圖呈現每次加油金額與區間油耗趨勢，並統計平均油耗、每公里油錢、累計加油金額及平均油價。
- **車輛證件**：可上傳、預覽、更換或刪除行照、駕照與強制險的圖片或 PDF。
- **CSV 備份**：保養頁匯入／匯出保養與驗車 CSV；油耗頁匯入／匯出獨立的油耗 CSV，互不覆蓋。

預設車輛為「小白」，車牌 `PAB-6992`，目前里程 3,020 公里；預設含兩筆保養紀錄、兩筆驗車紀錄與五筆示範加油紀錄。加油紀錄每次約 5 公升，單價為每公升 28 至 30 元。

油耗以相鄰兩筆加油的里程差除以後一筆加油量估算，假設每次皆加滿；第一筆只作為起算里程。為提升準確度，請每次都加滿後記錄。

每次開啟 App 時，本機伺服器會向中油官方網站刷新牌價；油耗頁顯示 92／95／98 價格與公告日期，也可按「更新」手動重查。若無網路或無法解析中油公告，頁面會提示無法查價；每公升價格僅供參考，仍可輸入收據上的加油總金額完成新增。同一個頁面工作階段會沿用已取得的牌價。

## CSV 欄位

匯出的 CSV 使用 UTF-8 編碼。保養與驗車 CSV 欄位如下：

```text
類型,車名,車牌,次數,日期,總里程(公里),保養內容,目前里程(公里),保養費用(元)
```

費用可留空，未填的舊紀錄視為 0 元。

油耗 CSV 使用獨立欄位：

```text
車名,車牌,日期,總里程(公里),加油量(公升),單價(元/公升),油品,加油金額(元)
```

日期格式為 `YYYY/MM/DD`。匯入各類 CSV 只會取代該類資料，不會覆蓋另一類紀錄。保養頁仍支援舊版七欄保養 CSV；油耗頁支援舊版六欄及含油品的七欄 CSV，也可匯入先前匯出的合併 CSV。舊油耗資料沒有總金額欄時，會以公升數乘單價計算。

行照、駕照與強制險是二進位檔案，不會包含在 CSV 中。

## 資料保存與隱私

保養、驗車、加油及車輛資料保存在目前瀏覽器與網址的 `localStorage`；行照、駕照與強制險檔案保存在同一瀏覽器的 IndexedDB。資料不會上傳到伺服器，也不會在不同瀏覽器或裝置間自動同步。清除瀏覽資料或更換裝置前，請先匯出 CSV；證件檔案需另外自行備份。

此原型不會額外加密證件檔案。請勿在不受信任的共用裝置上儲存敏感證件。
